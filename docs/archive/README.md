# 归档文档目录

本目录包含 Open Interpreter 企业级服务器分支的历史文档、临时记录和已完成的设计方案。

## 📁 目录结构

### optimization/
包含性能优化和架构改进的相关文档：
- `README.md` - NimChat Flutter 应用架构文档（历史参考）
- `session_optimize.md` - 会话优化方案
- `session_recovery_optimization_plan.md` - 会话恢复与活跃实例管理优化计划

### troubleshooting/
包含问题修复和故障排除的相关文档：
- `fix_procedure.md` - 代码块格式化问题修复流程
- `code_format_fix.md` - 代码块格式化问题修复指南
- `FIX_SUMMARY.md` - 已修复问题的总结记录

### testing/
包含测试报告和兼容性验证的相关文档：
- `INTEGRATION_TEST_SUMMARY.md` - OpenAI API 集成测试总结报告
- `OPENAI_API_COMPATIBILITY_REPORT.md` - 详细的API兼容性报告

### handover/
包含任务交接和项目状态的相关文档：
- `HANDOVER_CLINE_VERSION.md` - OpenAPI文档生成任务交接文档
- `HANDOVER.md` - 任务交接的完整记录

## 💡 使用说明

这些文档主要用于：
1. **历史参考** - 了解项目的发展历程和设计决策
2. **问题解决** - 参考类似问题的解决方案
3. **技术债务跟踪** - 记录已解决的问题和未完成的优化
4. **知识传承** - 为新团队成员提供背景信息

## ⚠️ 注意事项

- 归档文档的内容可能已过时，不应作为当前操作的依据
- 如需最新信息，请参考项目根目录和 `docs/` 目录下的活跃文档
- 归档文档可能会定期清理，重要的信息应该迁移到活跃文档中
